# EduBot AI - Intelligent Student Assistance Chatbot

## Overview

EduBot AI is a Java-based intelligent chatbot developed to assist students with academic queries. The chatbot uses NLP-inspired keyword processing and a rule-based response engine to provide relevant answers to frequently asked questions.

The application includes a graphical user interface (GUI) built using Java Swing, making interaction simple and user-friendly.

## Features

* Interactive chatbot communication
* NLP-inspired keyword detection
* Rule-based AI response engine
* Student FAQ handling
* Sentiment detection (Happy, Sad, Angry, Confused)
* Chat history management
* Unknown question learning mechanism
* Java Swing GUI interface
* Object-Oriented Programming (OOP) architecture

## Technologies Used

* Java
* Java Swing
* HashMap
* File Handling
* OOP Concepts

## Project Structure

* Main.java

* FAQDatabase.java

* LearningManager.java
* ChatHistoryManager.java
* ChatBotGUI.java

## How to Run

1. Open terminal in project folder
2. Compile all files:

javac *.java

3. Run the application:

java Main

## Sample Queries

* course
* I am happy

## Learning Mechanism

Unknown questions are automatically stored in:

* unknown_questions.txt

Chat conversations are automatically stored in:

* chat_history.txt
